## Generated/constructed placeholders

- `/images/properties/marin/night-1.*` and `/images/properties/vela/night-1.*`: AI-generated evening edits referencing each corresponding base photograph. These are labelled as atmosphere studies wherever shown.
- `floorplan.svg`: original schematic placeholders, deliberately generic and not to scale.
- `stone.webp`, `oak.webp`, `glass.webp`: crops from representative interior photography, not verified material specimens.
- `/icon.svg`, `/brand/monogram.svg`, `/brand/wordmark.svg`: original simple identity graphics for this fictional project. The SVG wordmark uses a system serif when viewed independently; the website uses the specified self-hosted font system.

## Fonts

Manrope, Cormorant Garamond, IBM Plex Sans Arabic via `next/font/google`, with `display: swap`. No commercial Neue Haas font file is included. Local system fallback only.
